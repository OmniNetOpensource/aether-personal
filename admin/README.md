# 阿芒 · Aether 管理看板

本仓库 `admin/` 目录中的调用观测、模型选择与服务凭证配置后台，使用原生 ES modules 和 Node 内置 HTTP 服务，无第三方依赖、无构建步骤。看板与聊天客户端分别部署。

## 本地启动

需要 Node.js 22.9 或更新版本，Go 后端已完成 model_calls 迁移并运行。

```sh
cd admin
cp .env.example .env
npm start
```

以上命令从仓库根目录执行；也可直接在根目录运行 `make admin`，或通过 `./start.sh` 统一启动聊天前后端与看板。

打开 http://127.0.0.1:5174 。仅输入管理员密码即可进入，无需邮箱或验证码。在仓库根目录执行 `python3 scripts/set-admin-password.py` 设置密码，完成迁移并重启 Go 后端。密码哈希只在后端 `.env` 的 `ADMIN_PASSWORD_HASH` 中配置，不放进看板前端。

可用 `python3 scripts/set-admin-password.py --generate` 生成初始密码，明文保存到后端项目的 `backend/bin/admin-password.txt`，该文件不会提交。修改密码并重启后端后旧看板会话失效。未配置密码时关闭管理入口。

看板令牌固定 12 小时有效，仅保存在当前标签页的 sessionStorage。退出立即撤销该会话。聊天继续使用邮箱验证码，两个入口的令牌互不通用。管理员密码是共享凭证，不能识别具体个人。后端全局每分钟最多接受 10 次登录尝试。
`npm start` 实际执行 `node --env-file-if-exists=.env server.mjs`，自动加载本目录的 `.env`；此参数需要 Node.js 22.9 或更新版本。也可直接配置进程环境变量后执行 `node server.mjs`。

`API_UPSTREAM` 是服务端固定的 Go 后端源站；不支持 URL 路径、凭证或任意目标代理。浏览器只访问同源 `/api`，不需要 CORS，也不包含 OpenRouter、数据库或供应商密钥。会话令牌保存在当前标签页的 sessionStorage，退出时撤销。

## 部署

将本目录单独部署，运行 `npm start`，由 HTTPS 反向代理转发到 `127.0.0.1:5174`。配置 `HOST`、`PORT`、`API_UPSTREAM` 环境变量；密码哈希 `ADMIN_PASSWORD_HASH` 只存在后端环境。不要把 `.env` 作为静态资源发布。看板代码与后端位于同一 Git 仓库，独立运行，不嵌入 Lynx 聊天客户端构建产物。

## 数据口径

- 调用是新日志记录的模型 HTTP 尝试，和包含工具、等待、重试恢复的执行步骤分开。崩溃窗口可能留下中断 / 结果未知。
- 费用为模型提供方返回的已知 USD 小计；缺少费用的调用单独计数。它不包含搜索等服务成本。
- Token 缺失显示未知，明确返回的 0 才是已知 0。平均耗时只计算观测到完成的请求。
- 工具分布是模型提出的工具调用名称，不能当作已经执行成功。
- 历史步骤未接入调用日志时不回填，不混入新调用统计。
- 提供运行概览、模型调用、运行过程、模型配置和服务配置五个页面。运行过程选择用户与 Agent 后按时间展示输入、推理、工具调用与结果，长内容可加载全文。模型调用每页最多 50 条，可加载下一页；分页浏览时暂停自动刷新，刷新或更改筛选条件后恢复。配置页仅手动刷新。时间在界面按浏览器时区显示，请求使用 UTC。
- 每条调用详情独立读取实际请求与响应 JSON，可格式化查看和选中文本。包含消息上下文与工具定义，不保存 HTTP 认证头。旧日志显示未记录。非 JSON 响应显示原始文本，超过模型客户端 8 MiB 接收上限时明确标记截断。

验证语法：`npm run check`。不包含测试文件。

## 模型配置

侧边栏“模型配置”可分别选择 Main 与 Subagent 模型，也可让 Subagent 跟随 Main，点击应用保存。作用于所有用户，从下一次请求生效，已发出请求继续完成。Go 后端先执行全部迁移（包含 `00007` / `00008`）；配置持久化在 PostgreSQL，服务重启仍保留。环境变量仅提供未保存时的默认值。可选目录经后端按工具调用与文本输出能力筛选；价格为目录估算。管理员并发修改时，过期版本返回409，请刷新后重选。

后端 `MAX_OUTPUT_TOKENS` 默认8192，实际请求还会按保存时目录中已知的模型输出能力缩小；包含推理 Token。避免模型默认预留过大输出空间，实际账户余额仍由 OpenRouter 校验。

## 服务配置

“服务配置”页管理 OpenRouter、ikun Gemini、Resend、Serper、Parallel 和 EveryInfra。填写新 Key 替换，留空保留，点击“清除 Key”后续请求停止使用该服务。Gemini 地址默认 `https://api.ikuncode.cc`，只需填写 Key；Resend 同时填写发件人。保存不请求供应商，因此“已保存 · 未验证”不代表额度、权限或可用性通过验证。

后端先执行全部迁移并配置 `SERVICE_ENCRYPTION_KEY`，即使没有业务 Key 也能进入看板。Key 只以密文进入数据库，浏览器仅收到末尾四位和更新时间。现有 `.env` 使用 `make -C backend import-services` 一次性迁移，之后从看板维护。主密钥需单独备份，配置语义见 [架构 Wiki](../docs/wiki/08-admin-observability.md#服务凭证管理2026-10-30)。
